# 🏢 Chào mừng đến với YBIM Software Ecosystem

Tôi là **Hoàng Y**, phát triển các giải pháp phần mềm tự động hóa và tối ưu hóa cho quy trình Building Information Modeling (BIM).

## 🚀 Hệ sinh thái Phần mềm Nổi bật

*   **[BIM-QAQC](https://github.com/YBIM-Sketch/BIM-QAQC):** Giải pháp chuyên nghiệp phục vụ công tác kiểm định chất lượng mô hình.
*   **[BIM-QS](https://github.com/YBIM-Sketch/BIM-QS):** Phần mềm độc lập giúp kỹ sư QS trích xuất khối lượng tự động từ các mô hình BIM, ứng dụng AI Z-Score & Isolation Forest.
*   **[YBIM_TDTC](https://github.com/YBIM-Sketch/YBIM_TDTC):** Quản lý Tiến Độ Thi Công BIM 4D/5D & Tối Ưu Hóa AI.

## 🛠 Công nghệ & Công cụ 
- **Ngôn ngữ & Framework:** Python, PySide6 (UI Desktop).
- **Môi trường:** Agent Antigravity tự động hóa quy trình.
